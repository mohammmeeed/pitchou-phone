# TikTok Shop / DatingKit React App

Application web moderne de découverte et matching inspirée de DatingKit et TikTok, développée avec React et Vite.

## Fonctionnalités
- **Flux vertical style TikTok** : Défilement vers le haut et le bas pour passer d'une carte à l'autre.
- **Balayage horizontal (Like / Dislike)** : Glissement horizontal fluide sans inclinaison.
- **Transition proportionnelle 1:1** : À mesure que la carte se rapproche du bord latéral, la carte suivante remonte dans la même proportion pour prendre sa place.
- **Description rétractable style TikTok** : Prévisualisation sur 2 lignes avec `... plus` et déploiement complet sur 5 lignes avec `moins`.
- **Interface mobile responsive** : En-tête avec navigation, tiroir latéral et barre de navigation inférieure.

## Installation et Lancement

```bash
cd frontend
npm install
npm run dev
```

## Compilation pour Production

```bash
cd frontend
npm run build
```
